# KnowFlick 项目全案：现状与未来计划

盘点日期：**2026-11-12**。范围：当前分支 `workbench/second-brain-validation`、HEAD `ca0858d`，含仓库里正在开发的未提交内容；发布状态只引用仓库的发布记录。本文汇总已有决定、代码现状、验收证据与后续计划，用来查资料和拆任务。具体契约仍在原文维护。

KnowFlick 的主线是 **笔记 → 知识库 → 应用**：把网页、文件、灵感、邮件或录音变成可继续编辑的笔记，把有出处的内容纳入知识库，再用于找回、问答、学习、复盘和创作。原有剪藏、AI 出卡、刷卡、收藏、测验、统计与导出继续保留。本地基础功能无需账号、联网或模型密钥；模型、自选存储和外部工具接入按需开启。桌面三端和未来 Web 共用一套界面，Android 延续 Kotlin/Compose，平板需求先考虑 Android 平板。

## 如何判断一项功能的状态

- **已有实现**：当前工作树有入口和对应代码。它可能只存在于分支或未提交改动。
- **有限可用**：有可运行的路径或自动化验证，但某个平台、真实数据或外部服务尚未验收；限制随条目列出。
- **已验收**：证据与所说的配置、样本和平台一致，例如“macOS 标准配置安装态、合成数据的 MCP 项目授权与撤销”。不能把范围内通过外推为全平台通过。
- **已发布**：有相应发布记录或发行证据。工作树、CI 产物和发布是三种状态。
- **计划 / 待决策**：能力已入路线，或仅是方案；尚无实现、未过验收或需独立选型，按条目说明。
