# 能力目录与需求映射

日期：2026-10-24。这里列的是目标能力，不是已上线清单。当前证据见 [产品基线](README.md#当前有哪些基础) 与 [既有验收表](../FIRST_VERSION_ACCEPTANCE.md)。R0–R5 定义见 [交付路线](DELIVERY_ROADMAP.md)。

“首期”表示最早交付该能力的可用子集；后续增强仍保留在同一编号下。以下按能力分类覆盖代表性笔记产品的模式，不宣称穷举全部产品、所有版本和所有功能。

## A. 信息进入笔记

- **A01 闪念捕捉｜R1，增强 R3**：快捷键、托盘、桌面可关闭的灵感球、手机快捷入口；文字输入、草稿、自动保存与失败保留。灵感球是同一捕捉面板的入口，不另造一套笔记。
- **A02 网页剪藏｜已有基础，R1 验证，R2 扩展**：URL、选中文本、正文、出处、抓取时间、快照；浏览器扩展与移动分享后续加入。登录页或失败时允许手动贴正文，不绕过访问限制。
- **A03 手动笔记｜R1**：短记与长文使用同一笔记模型；空白新建、继续编辑、撤销重做、保存状态、标题、置顶和归档。
- **A04 图片与截图｜已有附件基础，R2**：粘贴、拖入、拍照、批注；保留原图，OCR 是派生内容，有进度与失败状态。
- **A05 语音笔记｜已有基础，R0/R2**：先可靠录音落盘，再异步转写；回放、定位时间点、编辑转写、导出音频；实时识别为后续增强。
- **A06 视频｜R2 导入与引用，R5 强化**：文件/链接、封面、字幕、带时间点的笔记与转写。大文件默认先说明保留方式；不把简介抓取称为视频内容理解。
- **A07 手写｜已有基础，R3 Android 平板，R5 强化**：矢量笔迹、撤销、橡皮擦、画笔；后续压感、套索、防误触、手写 OCR 与检索。保留可编辑笔迹，不能只留截图。
- **A08 会议｜R2**：录音/导入音频 → 可编辑转写 → 引用时间点的纪要/决策/待办；说话人标注先允许人工，自动分离按设备成本后置；长录音支持中断恢复。不会自动发纪要或创建外部任务。
- **A09 邮件｜已有只读 IMAP，R2**：分别规划 Gmail API/OAuth、Microsoft Graph/OAuth、QQ 授权码/IMAP 与经核实的网易/其他 IMAP 适配；账号范围、文件夹/标签、日期过滤、增量游标、重复隔离、附件按需取。OAuth 与各服务真实验收单列，不用预设数量充当兼容范围。
- **A10 文件｜已有部分，R2**：Markdown/TXT、PDF、DOCX/PPTX/XLSX/CSV、EML、图片/音视频；保留原件，呈现转换报告和失败明细。扫描 PDF 依赖 OCR；表格公式、批注、宏和复杂排版不承诺无损编辑。
- **A11 外部笔记导入｜R2 起，R5 扩展**：先通用 Markdown/HTML/ENEX/ZIP，再按证据加入 Obsidian、Joplin、Notion、Evernote、OneNote、Apple Notes、思源等适配；保留目录、标签、附件、链接与来源 id，能保留多少须逐格式列明。
- **A12 手机笔记接入｜R3 起**：系统分享、导出文件、用户选定文件夹或官方 API；不能直接读取任意手机应用的私有数据库。导入向导显示“一次导入/持续拉取/双向同步”的真实级别。
- **A13 主动来源｜已有订阅基础，R2 强化**：RSS/Atom、GitHub、技术社区、阅读稍后看与参考文献资料；网站专用适配后续扩展。对话中按需联网寻找材料，先推荐候选，经用户确认再入库；订阅规则可暂停，显示上次成功与失败项；不能静默无限采集。
- **A14 通用入口｜R2/R3**：拖放、批量导入、文件夹监视、移动扫描、选择后粘贴；书签、浏览器导出、阅读高亮、聊天记录/日历的用户导出作为扩展方向。剪贴板监听明确启用并可暂停。

## B. 笔记编辑与组织

- **B01 基础编辑器｜R1**：标题、段落、列表、待办、引用、代码块、链接、图片、基础表格、Markdown 快捷输入、查找替换、字数；键盘、输入法、无障碍、离线和崩溃恢复必须一起验收。
- **B02 笔记生命周期｜R1**：自动保存、未保存提示、历史版本、回收站、恢复、复制与导出；编辑正文不覆盖导入原件。
- **B03 组织｜R1**：笔记本/文件夹、标签、收藏、置顶、归档、批量移动和筛选；一条笔记可属于多个知识库，基础路径不要求多层目录。
- **B04 关联｜R2**：笔记链接、反向链接、选段引用、附件与原始来源定位；改标题不破坏内部 id 引用；失效引用有明确提示。
- **B05 模板与日记｜R2**：日记、周记、会议、阅读、项目模板；变量、可编辑字段、重复创建规则；避免模板生成空笔记洪水。
- **B06 多媒体混排｜R2**：一篇笔记中包含文本、图片、录音和手写附件；不同记录方式不各自生成彼此不相通的孤岛。
- **B07 阅读与标注｜R2/R5**：PDF 阅读与高亮、网页选段、音视频时间点批注；后续 EPUB、文献与引文管理接入。原文件和标注引用一起导出。
- **B08 属性与多视图｜R5**：自定义字段、筛选、排序、分组、表格/看板/日历视图、关系与公式；使用相同内容 id，不复制为另一套数据库。
- **B09 画布与知识图｜R5**：思维导图、白板、局部关系图、块引用/嵌入、数学公式与图表；局部加载，不能用全库图渲染阻塞主编辑器。
- **B10 任务与提醒｜R2 基础待办，R4 目标关联，R5 增强**：明确截止时间与用户确认的提醒；可关联项目、周期任务和日历。笔记内待办不自动升级成外部日历事件。
- **B11 高级写作｜R5**：专注模式、目录大纲、拆分窗口、版本对比、发布版式、写作辅助；多人评论、协作编辑与分享发布作为可选模块需求登记，依赖自建服务与权限模型再排实施批次。

## C. 笔记成为知识库

- **C01 知识库范围｜R1**：用户创建主题/项目知识库，手动加入笔记或使用筛选规则；默认索引全文；不同范围检索不串库。
- **C02 混合检索｜已有卡片基础，R1 全文/R2 原文切片**：关键词、中文短词、语义、标签与时间筛选；结果能读到原文。无模型时保留全文检索，不把字符哈希包装为语义模型。
- **C03 有出处的知识提炼｜已有出卡基础，R2**：摘要、概念、事实、问题、决策；多来源引用与冲突并列。人确认后才成为可复用结论；引用失效或原文更新时标识需复核。
- **C04 去重与版本｜R1 字节级基础，R2 近似建议**：同一附件共享字节；同来源更新形成修订；语义近似仅建议合并，显示差异，保留独立出处。
- **C05 知识维护｜R2/R4**：收件箱待整理、缺出处、过时、相互矛盾、待验证与需重建索引；用户可以忽略提醒，不强迫清空收件箱。
- **C06 关联与主题页｜R2/R5**：关键词/实体/项目关联、自动候选标签和主题目录；先建议、可撤销；不把模型猜测当用户事实。
- **C07 原件与可重建索引｜R1/R2**：原件、用户笔记和派生结果分开；删除缓存不丢内容；换模型、换切片方法可重建，有进度、可暂停。
- **C08 知识可携带｜已有基础，R1 强化/R3 协议**：Markdown+附件、JSON、完整备份、旧 cards.json、Anki TSV；清楚列出可移植和专有能力，附件与引用不能丢。

## D. 知识库应用

- **D01 知识问答｜已有基础，R2**：先选范围再提问，给原文引用、时间与不确定项；资料不足时说明缺口。联网补充单独标注，不与私人知识混作同一来源。
- **D02 原有学习闭环｜保留，R0 回归/R2 衔接**：出卡、刷卡、复习、测验、收藏历史、掌握度、学习统计与导出；旧卡片、评分和学习进度不重置。
- **D03 生活/工作复盘｜已有简报基础，R4**：日/周/月/项目总结、变化趋势、反复出现的议题与可回看的旧内容；每条具体事实能点回原记录。
- **D04 目标与建议｜R4**：用户明确设定目标和完成条件，关联行动证据；区分“未记录进展”与“目标失败”，建议支持采纳/驳回；不凭记录少就评价一个人的生活。
- **D05 个人画像｜R4**：职业/项目、兴趣、表达偏好、用户确认的长期目标；区分主动填写、行为统计和 AI 推测，显示证据/时间/范围；可编辑、过期、删除、暂停学习。
- **D06 项目记忆｜R4**：项目背景、决策、约束、未决问题与变更，按项目导出给 AI 工具；项目过期/封存不继续污染其他项目上下文。
- **D07 创作工作台｜R4/R5**：素材检索 → 选取证据 → 大纲/文稿 → 人工修改 → 导出；营销、自媒体、研究、开发等用模板组织。外部发布和代发分别授权实现。
- **D08 应用模板｜R4/R5**：会议纪要、阅读总结、周报、学习计划、方案对比、营销素材包；共享一套知识范围和引文规则，不各做独立数据孤岛。
- **D09 主动回顾｜R4**：用户选频率与项目范围，安静时段、暂停和退订；只提醒可处理事项，避免把每次收集变成通知。

## E. 本地、开放与扩展

- **E01 本地基础与离线｜R0/R1**：无登录完成笔记、整理、全文检索和导出；本地模型可选、按需下载；每种 AI 任务明确实际数据去向。
- **E02 存储连接器｜R3 起**：优先 WebDAV、S3 兼容/MinIO；再评估 Nextcloud、坚果云、Dropbox、OneDrive、Google Drive。先备份，再单向复制，最后多端同步，各等级分别验收。
- **E03 同步与冲突｜R3**：设备状态、增量传输、可见冲突、删除墓碑、断线恢复、附件校验、版本兼容；不能把“把 SQLite 放网盘”作为多端方案。
- **E04 数据保护｜R1/R3**：凭据独立存放、可选库锁/静态加密、备份加密、同步 E2EE、恢复密钥分别说明；锁屏图标不代表数据库已加密。共享设备/企业管理是后续明确场景。
- **E05 模型配置｜已有基础，R2 强化**：本地/自定义端点、按任务选择模型、下载/升级/卸载、调用成本与失败重试；外部模型不可用时基础记录继续工作。
- **E06 MCP｜已有基础，R4 授权改造**：范围、只读/写入、字段过滤、审计和撤销；外部工具不得默认读取全库或永久画像；写入用户授权收件箱而不是覆盖原文。
- **E07 技能包与 API｜R4/R5**：导出某项目的 Markdown 上下文、来源清单与调用说明；适配具体 Agent 的 Skill 格式；CLI/本地 API/自动化需有权限与版本契约。
- **E08 模块中心｜已有清单，R1/R2 生命周期，R5 生态**：发现、启停、资源/下载占用、权限、更新与卸载；停用模块仍可读它生成的内容。官方模块可内置惰性加载，第三方隔离另验收。
- **E09 性能与存储治理｜贯穿**：后台队列限并发、可取消、按需加载、缓存配额、模型回收、原件保留策略、容量分析、孤儿附件安全清理；查看将释放什么，再确认清理。
- **E10 开源可维护性｜贯穿**：MIT 主体、第三方许可清单、数据协议、迁移说明、连接器测试夹具、失败诊断、安装升级和无障碍；不以“开源”替代质量责任。

## F. 平台适配

- **F01 桌面｜R1 起**：Windows/macOS/Linux 一套界面与领域逻辑，本机能力用宿主接缝；键盘、分栏、拖放和快捷捕捉优先。
- **F02 手机｜R3 起**：Android 保留原能力并逐批接新笔记契约；分享、拍照、录音、快速找回优先；单页与底部导航，不压缩桌面三栏。
- **F03 平板｜R3 基础/R5 手写强化**：Android 平板双栏、横竖屏、触控笔、手掌防误触、分屏阅读批注；iPadOS 需另做平台决策，现阶段不承诺已支持。
- **F04 Web｜R5**：复用 Web 界面，独立验证文件持久化、权限、模型和后台限制；没有我方云账号时允许用户接自建后端，不能冒充桌面本地能力。

## 本次原始诉求的覆盖核对

网页/灵感/键盘/手写/语音/视频/图片 → A01–A07；邮箱 Gmail/QQ/163/网易 → A09；其他手机笔记 → A11/A12；平板与会议 → A07/A08/F03。

主流笔记能力有序整合 → B01–B11；一级简洁、深层可展开 → [UI 方案](UI_SPEC.md)；本地、MIT、自选存储、模块轻量 → E01–E05/E08–E10。

笔记到知识库、RAG、原件/向量、去重 → C01–C08；画像、生活工作复盘、目标建议 → D03–D05；开发项目记忆、MCP/Skill、行业应用和自媒体素材 → D06–D08/E06/E07。

既有需求不减 → D02、C08、F02 及既有平台功能。后续发现的新能力继续加编号与阶段，不能以“目录已经写完”阻止合理增补。
