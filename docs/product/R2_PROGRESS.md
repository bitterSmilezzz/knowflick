## R2 退出门槛对照

「不同来源都完成导入 → 搜索 → 打开原件 → 引用 → 修改/删除后的更新；来源失败可重试且不重复建笔记；禁止仅以支持扩展名数量验收」：

- **文件来源**：导入（26 项冒烟）→ 搜索（FTS 全文）→ 打开原件（EntryInspector）→ 引用（R1 附件引用 + 映射笔记）→ 修改/删除更新（materials 编辑流 + 软删 + FTS 同步）——链路成立；
- **网页来源**：剪藏链路（clipEngine 三端一致 + 真实页面冒烟）——成立；
- **邮件来源**：界面/落库/错误文案已验，**真实服务器收信待验**（需账号）；
- 来源失败可重试且不重复建笔记：幂等重跑冒烟 + contentHash 去重；
- 真实查询集（≥100 条中英混合检索问题、首 5 条命中率 ≥90%）**未建**——统一质量目标里的这项需要人工标注语料，是独立任务不是代码任务。
