# 界面与交互方案

日期：2026-10-24。状态：设计建议，尚未修改正式应用。对照基线为 `Workspace.tsx`、`UI_CONSOLIDATION.md` 和 `NOTES_HANDWRITING_VOICE.md`。

## 设计方向

以安静、清楚的笔记工作区为主体。用户先看到内容和下一步动作，来源、处理管线、模型及容量管理按场景展开。简洁通过层级和上下文实现，不通过删除能力或把所有功能藏进深菜单实现。

延续已有桌面分栏、键盘和系统主题基础，不重新造一套各系统独立界面。正文使用系统字体与稳定行宽；应用壳、列表和编辑区的层级主要靠留白与细分隔，而非大面积卡片、渐变或统计看板。学习卡片原有摄影视觉保留在学习场景。

## 桌面主导航

一级目的地只有三个：**笔记 / 知识库 / 应用**。顶部提供一个“新建”动作与全局搜索；底部保留设置和轻量状态。新建、搜索与设置不计为第四层产品职责，但也不能在视觉上形成十几个同权重按钮。

```text
KnowFlick                   搜索（Cmd/Ctrl+K）
+ 新建

笔记
  收件箱 · 最近 · 笔记本 · 收藏 · 回收站
  来源管理 → 邮箱 / 订阅 / 文件 / 外部笔记

知识库
  全部 · 我的知识库 · 项目 · 待整理

应用
  问答 · 学习 · 复盘 · 创作 · 项目记忆 · 产物

设置                        本地已保存 / 同步状态
```

以上是信息树，不是默认全部展开的侧栏。默认仅展开当前目的地；最近使用的 2–3 个知识库可固定。模块关闭时应用项不占空位；已有学习用户升级后学习入口继续固定可达。

来源管理是一个二级管理页，显示连接状态与规则，不与“写笔记”“使用知识”争抢首页。收件箱属于笔记视图，仍可从新建成功回执直接打开。

常用功能目标路径：新建 ≤1 次点击，收件箱/搜索/当前知识库 ≤2 次，来源连接/批量导入/模块管理 ≤3 次。层级超过这条预算时使用上下文动作或命令面板，不能继续加第四、第五层菜单。

## 桌面布局与三个工作面

导航约 192–240px，列表约 260–340px，正文占剩余宽度；这些是设计起点，尊重现有分栏拖动、最小宽度、记忆与键盘操作。低宽度时折叠列表或导航，正文不得被挤成窄缝。

### 笔记工作面

默认是导航、笔记列表、编辑区。详情的来源、属性、反向链接放可收起的右侧检查器，AI 也是按需抽屉；不常驻第四栏。

正文顶部只有标题、保存状态和更多操作。主要编辑工具在选中文本或斜线菜单出现，键盘能完成同样动作；基本格式入口仍可发现，不能只靠悬停。附件在正文相应位置展示。

“新建”默认直接得到可写笔记。其展开菜单含文字、录音、手写、剪藏和导入；最近使用的记录方式可固定，但不把所有输入方式永久平铺在左栏。笔记可以边写边增加媒体，不要求先决定一种不可更改的类型。

选中多条才显示批量工具栏。长期不常用的导出备份移入文件菜单/设置，选中笔记的导出在笔记操作菜单；现有导出能力继续可达。

### 知识库工作面

左侧选择知识库，主区默认显示相关笔记与确认的知识，顶部仅有“搜索此库”“提问”“整理”。集合范围、自动加入规则和成员说明在库设置里。

每条内容展示类型、简短摘要与出处。用户可打开原笔记或原件，不必进入知识卡。知识库可有“概览 / 内容 / 关系”视图，关系图后期开启且局部加载。概览显示项目说明、精选结论和未决问题，不默认铺满统计块。

“整理”展示候选分类、近似重复、冲突结论和需复核内容，一次处理一组，保留撤销。AI 自动生成的知识先显示为建议；用户自己创建的笔记无需 AI 审批即可保存和检索。

### 应用工作面

首次进入只提供少量可用应用及“添加应用”。每个应用先选择知识范围，再运行，不直接继承整个私人资料库。

问答界面让回答与出处同屏；点击引文展开对应段落、页码或录音时间点。复盘明确显示日期范围、引用记录与“未记录”的部分。学习继续沿用卡片、评分和测验；创作支持选择素材、生成草稿、修改、导出。

产物保存在本地并带来源快照版本；可“保存为笔记”，但默认不自动把生成内容反复喂回长期画像和知识索引。

## 灵感球与全局捕捉

灵感球是可选入口，默认使用系统快捷键和托盘，避免遮挡当前工作。球的位置、显示/隐藏、快捷键可配置；窗口不抢走当前编辑内容，不在全屏会议时强制显示。

捕捉面板先给一个输入区，底部仅文字/录音/手写/附件切换。贴 URL 后识别为链接，后台抓取；**先保存用户输入，再处理外部内容**。网络失败仍有一条可继续处理的笔记。

保存后给出“已保存到收件箱”回执和查看入口；只有持久化成功才关闭。Esc 收起并保留草稿；输入法确认不得误保存；关闭窗口和退出进程的草稿策略一致。音视频任务可继续在后台运行，能暂停/取消并显示位置。

## 手机

Android 首先落实拍照/分享/录音/闪念与找回，而非把桌面三栏缩小。底部三个目的地：笔记 / 知识库 / 应用；右下或底部主动作只有一个“记录”，在键盘弹出时保持不遮正文。

笔记页显示搜索、收件箱和最近笔记，笔记本/来源管理进二级页。编辑全屏，格式工具在键盘上方；录音显示明确录制状态，后台与来电中断有恢复策略。分享进入后先显示接收到的内容与保存位置，可一键完成。

触控目标至少 44pt 的设计尺度，Android 落地按平台 dp 规范执行。所有重要动作可用读屏和系统返回完成；不能让横向滑动和系统返回冲突。弱网及无网不会阻止本地保存。

手机与桌面可有不同功能优先级，但相同笔记必须能安全读取。暂不支持编辑的块显示只读预览，不能在手机保存时删除未知块。

## 平板

Android 平板横屏双栏“笔记列表 + 内容”，竖屏单栏；允许阅读资料与笔记分屏。触控笔工具可常驻在手写模式，普通文字模式保持收起。手掌防误触、压感、橡皮擦、套索、撤销与选段引用要在真实触控笔设备验证。

手写和文字可处于同一笔记。OCR 文本作为可修订的派生层，搜索结果定位到对应笔迹或页面。iPadOS 不在现有平台承诺内，另评估原生输入与壳能力后再决定路线。

## 设置与模块中心

设置一级分组建议为：外观与操作 / 数据与备份 / 连接来源 / 模型与 AI / 同步 / 功能模块 / 隐私与外部访问。使用页内分组和搜索，避免同一页堆几十个裸配置框。

连接器呈现真实状态：未连接、授权过期、同步中、部分失败、上次成功。模型呈现未安装、下载中、可用、加载失败；既无模型也无密钥时，不让 AI 按钮假装工作。

每个重模块展示用途、下载体积、预计运行资源范围（实测后填写）、权限和卸载方式。停用模块保留用户数据；“卸载模型”“删除缓存”“删除原件”是三个不同动作。

## 旧入口迁移

- 邮箱、订阅 → 笔记下的来源管理；仍可固定常用来源。
- 收件箱 → 笔记默认子视图；未处理计数保留。
- 全部知识 → 知识库的全部内容；旧素材在笔记仍可找到，旧卡片在学习与知识库可找到。
- 分类、收藏、归档 → 所属内容的筛选/组织，不作为产品主层。
- 知识问答、认知简报、统计、测验、温故 → 应用；已有启用设置保持。
- 产物库 → 应用中的产物，可从对应知识库反查。
- 手写、语音、转写 → 同一新建菜单和笔记附件动作。
- 导出备份 → 文件菜单和数据与备份；当前选中内容有单项导出。

新旧入口迁移必须维护一份可自动检查的路由对照。能力可达性、未保存草稿、浏览历史与深链接不应因导航重排丢失。

## 必须设计的状态

除了正常页面，还要有：空库首次记录、导入部分失败、采集无权限、授权过期、保存失败、磁盘满、离线、模型未下载、任务取消、冲突副本、原件缺失、引用过期、同步暂停、恢复中与旧版本只读。

用户输入优先保留。每个错误要说清楚“内容现在在哪里、下一步做什么”；后台失败不得用一个短暂提示条作为唯一回执。

## UI 验收

在 1280×800 小笔记本、宽屏、390px 手机及平板横竖屏检查；桌面最小窗口和 200% 文本缩放都须可用。浅深主题、对比度、焦点、读屏、键盘及输入法单列验证。

邀请未参与开发的用户完成：记闪念、续写、剪藏、找回、问答看出处、恢复备份。记录任务是否独立完成与失败点，不能用截图美观或按钮点击成功替代可用性。
