# KnowFlick Android v0.10.0

发布日期：2026-09-22。versionCode：20。最低 Android 8.0 / API 26。

## 本版变化

- 学科、分支、难度与学习范围统一建模，新增知识地图，兼容旧卡片分类与已有学习进度。
- 知识星图按学科分片，复用拓扑缓存，减少划卡和手势操作带来的重复计算。
- 新增网页剪藏：支持系统分享和手动输入链接，先预览正文，再由用户发起 AI 提炼入库；保留来源链接。
- 听书新增标准、温和、通勤、睡前四档预设及睡眠定时淡出。系统 TTS 的音量/语速变化作用于之后的朗读，云端音频的语速在生成时确定。
- 汇总 AI 生成、追问沉淀、搜索历史、错题复盘和局域网同步可靠性改进。
- 仓库附带本地 MCP/CLI 工具：默认只读、学科检索与学习路径、人工确认暂存、长连接自动刷新和并发写入保护。

## 安装与升级

在本 Release 下载 `KnowFlick-0.10.0.apk`。使用既有发布证书签名，可覆盖安装并保留本地数据；更新前可在 App 导出备份。
附件 `KnowFlick-0.10.0.apk.sha256` 用于核对下载完整性。

## 验证与边界

发布执行 `tools/build_android.sh`（JVM 单测、Lint、Release/R8、签名和 ZIP 对齐校验），另执行共享分类契约及 Node/Python 工具测试。详细结果见发布操作记录。
本版未重新采集 baseline profile；真实设备帧率、云端真人音色听感不作为此次自动化验证结论。
