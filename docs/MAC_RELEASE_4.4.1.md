# KnowFlick macOS v4.4.1

发布日期：2026-09-24。最低 macOS 14。

## 本版变化

- 将系统显式暂停命令与播放/暂停切换命令分开处理。重复的暂停命令保持暂停，不会恢复朗读；切换命令仍会按当前状态播放或暂停。
- 仅调整系统播控指令路由，不改卡片、朗读内容或持久化数据。

## 安装与升级

下载 `KnowFlick-4.4.1.app.zip`，解压后放入 Applications。已有卡库继续使用，无需重置。
附件 `KnowFlick-4.4.1.app.zip.sha256` 用于核对下载完整性。

## 验证与边界

- 本机运行 KnowFlickCore 测试与构建，并运行 shell lint、MCP 测试和学科契约检查。
- GitHub macOS workflow 运行完整 Swift 测试、应用打包、签名、资源和启动检查。
- 新增单元测试覆盖显式暂停的幂等行为，以及切换命令在播放与暂停之间的双向切换。测试不注册真实系统媒体命令；控制中心或硬件媒体键的完整系统会话行为仍需在 macOS 图形会话中验证。
