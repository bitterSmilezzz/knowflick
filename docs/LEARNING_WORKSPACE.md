# macOS 个人学习工作台

## 导入导出流畅度更新（2026-09-11）

本地文件读取、规则解析、完整内容生成和导出写入改为后台任务。导出预览最多处理前 3 张卡片，并限制样本字段和最终预览长度；预览明确标注截断，实际保存和完整复制仍保留全部原文。“复制预览内容”只复制样本，底部复制按钮复制完整结果。

修改原文、切换输入方式或关闭导入窗口会取消旧任务，不再回填过期结果；切换导出范围和格式会重建预览。导出操作使用点击时的卡片快照，处理期间防止重复提交和关闭窗口；保存错误持续显示。多文件导出收到取消时清理本次创建的目录。同步解析内部不会在每一行中断，但取消后不会更新界面。

验证：134 项测试、20 个 suite 通过。新增测试覆盖 400 张完整卡片的后台 JSON 写入→读取→解析一致性、全部导出格式的预览长度与完整复制范围、无效 JSON、写入失败和取消前不产生文件。

## 保存可靠性更新（2026-09-11）

卡片写入失败时，主窗口持续显示错误原因和“重试保存”入口；内存中的最新更改保留。重试成功后提示自动消失。主文件保存成功、但备份更新失败时会单独说明，不把两种情况混为一谈。异步保存结果按修改版本核对，旧任务的结果不会覆盖较新状态。

这一轮验证使用临时目录模拟主文件与备份写入故障；包括当前工作区其他已有测试在内，共 130 项测试、19 个 suite 通过。该提示目前覆盖卡片库保存，设置和聊天文件的保存反馈仍需后续统一。

## 产品方向

将原先“卡堆 + 隐藏功能菜单”的首页改成三个常驻页面：今日学习、复习计划、知识库。沉浸刷卡仍可从导航进入，并有返回工作台入口。沿用 SwiftUI、现有本地存储和原生菜单，不新增网页或依赖。

## 可用流程

- **今日学习**：真实卡库统计、每日目标（3 / 5 / 10 / 15 张，保存在本机）、下一篇阅读、学习路径和按主题进入的知识版图。
- **完成阅读**：详情底部固定操作，记录阅读时间并返回工作台。保留收藏、掌握程度和复习次数，不把“已读”当成“已掌握”。
- **复习计划**：首次阅读次日到期；回忆反馈为忘记 / 模糊 / 掌握时，分别在 1 / 3 / 7 个日历日后复习。到期优先，每轮最多 10 张，也可以只复习某一张。未来安排显示日期。无到期内容时可以自由测验。
- **知识库**：全文即时搜索、主题筛选、全部 / 未读 / 收藏 / 笔记 / 已掌握筛选、时间排序、收藏操作、打开阅读、导出当前筛选结果。
- **卡片编辑**：列表的铅笔按钮可修改标题、主题、摘要和正文；空内容不能保存，未保存退出会提示。卡片身份、收藏、来源和复习记录保留。右键菜单另可追问或导出单张卡片。
- **导航**：可以折叠；窄于 900 点时自动显示图标导航，每个图标提供名称和提示。主内容滚动，长标题可换行。

## 数据口径

`LearningPlan` 是独立的确定性计算模块。今日目标统计当天 `seenAt` 或 `lastReviewedAt` 命中的不同卡片，同一卡片计一次。现有数据只保存最近一次阅读和复习时间，因此不展示无法从历史数据可靠恢复的每日趋势或分钟数。阅读时长仅为按正文长度计算的估算。

复习间隔为透明、固定的产品规则，不宣称使用自适应记忆算法。到期状态每分钟刷新，并在卡库变化后立即刷新。每日目标是本机偏好，不随 JSON 卡片归档导出。

## 实现边界

- `LearningWorkspaceView` 负责工作台导航和展示；阅读、测验、导入导出复用已有页面。
- `LearningPlan` 根据已有卡片字段计算计划，无数据库迁移。
- `AppStore.completeReading` 只更新阅读时间并持久化。
- 现有 Dock 图标原图和 ICNS 保持一致；构建仍校验全部图标尺寸。
- 云端 AI / TTS 的实际服务质量不属于这次本地 UI 验收结论。
