## 一、核心功能与设计体系

### 1. 核心 SM-2 记忆模型引擎 (`SpacedRepetitionEngine`)
- **四档评分体系**：划分 `AGAIN (0/重来)`、`HARD (1/较难)`、`GOOD (2/良好)`、`EASY (3/容易)`，与知识测验（Quiz）及划卡手势无缝互通。
- **动态记忆间隔**：
  - 第 1 次复习：1 天。
  - 第 2 次复习：HARD 为 3 天，GOOD 为 6 天，EASY 为 7 天。
  - 第 3+ 次复习：当前间隔乘简易度因子 $I_{new} = \text{round}(I \times EF)$，EASY 额外享有 1.3 倍加成。
  - 简易度因子（EF）演进：根据用户评级动态调整，下限 1.3，上限 3.0。
- **艾宾浩斯遗忘曲线可提取率预测**：
  - 基于模型 $R(t) = \exp(-0.10536 \cdot t / I)$，以百分比（0%~100%）在卡片头部实时展示记忆留存率。
- **动态间隔预告（`previewNextIntervals`）**：
  - 底部自评按键实时根据当前卡片的真实记忆历史计算出如果选择「重来/较难/良好/容易」各自将获得的下次间隔天数。
- **数据与存储模型向后兼容**：
  - `KnowledgeCard` 扩展 `repetition: Int = 0`, `intervalDays: Int = 1`, `easeFactor: Double = 2.5`。
  - `CardJson` 完备编解码：旧卡数据与 macOS 端导出的 JSON 导入时自动填充缺省默认值，完全向后兼容。

### 2. 主刷卡流专属复习卡堆模式 (`Review Deck Mode`)
- **智能入口徽标**：常规模式下若存在到期卡片，顶栏标题右侧显示琥珀色「• 复习 N」徽标，支持一键切换。
- **沉浸式复习顶栏**：复习模式下独立渲染「专属复习卡堆 (N)」与「退出复习」轻量胶囊按钮，彻底杜绝小屏文本折行挤压。
- **卡片记忆留存率芯片**：卡片正面左上方展示「🧠 留存 X% · Y天间隔」。
- **底部四档自评按键**：复习模式下底部操作栏替换为 4 档颜色柔和的高辨识度自评按键，分别显示动态天数。
- **手势划卡映射**：左划等同于「重来」，右划等同于「良好」。
- **复习达标祝贺面板**：本轮到期卡片全部复习完毕后展示金星祝贺面板，统计本次强化张数，提供「返回常规探索卡堆」一键按钮。

### 3. 安卓 UI 深度扁平化美化（Flat Minimalist & Editorial UI）
- **温润纸白（`#FAF9F6`）与暖曜黑（`#121215`）双模基底**：彻底移除厚重 3D 阴影与粗糙渐变，呈现出版物般的纯净阅读底色。
- **4 阶通透摄影微遮罩**（`0.14f -> 0.28f -> 0.58f -> 0.80f`）：顶端通透保留摄影高光，中下部舒适衬托文字。
- **1px 极细微结构边框（Hairline borders）**：规范贯穿卡片、胶囊、弹窗与输入框。
- **低饱和淡雅微彩系统（Muted Pastels）**：鼠尾草绿、绯红玫粉、冰川灰蓝平托盘与胶囊，告别高饱和刺眼色块。
- **人文宋体大标题排版**：优化字偶距与行距（正文 `24.sp`，段间距 `18.dp`），大标题字间距微聚拢（`-0.3.sp`）。
- **学习统计中心（StatsScreen）全量重构**：消除硬编码深色容器，掌握度三色微彩卡与排程预测柱状图在浅色纸质与深色模式下均获得和谐自然的对比度。
- **设置页（SettingsScreen）与 AI 追问面板（CardFollowUpChatSheet）**：发丝边框与主题色彩深度统一，深浅色自动适配。

### 4. 全局全文检索与智能标签多维筛选系统（Search & Multi-Filter）
- 支持拼音全拼与声母模糊检索（如 `zzx` 检索中子星），彻底消除拼音与正文噪声误匹配。
- 来源与状态多维过滤（全部/精选/AI/收藏/足迹/待探索）与学科横向滑动分类 Chip。
- 卡片支持「置顶刷卡」与「进入详情」，支持实时收藏状态切换。

### 5. 知识库离线归档与全量备份恢复系统（Backup & Restore）
- 支持 JSON / Markdown / ZIP 全量离线归档导出，支持全量、收藏、历史三维范围。
- 支持导入恢复对话框与冲突合并机制，确保多端协同数据无损迁移。

### 6. 基于 Jetpack Glance 的桌面每日卡片微件（AppWidget）
- 提供小号（2x2）与中号（4x2）桌面微件，定时轮播每日精选知识，点击一键唤醒 App 并定位卡片。

### 7. 全功能离线语音朗读控制台与 Mini Player 悬浮播控条
- 支持毫秒级定位拖拽、语速语调微调、磨耳朵翻卡停顿间隔与睡眠定时器；
- 主卡堆支持悬浮 Mini Player 播控条，随时随地听知识。

### 8. 知识卡片分享海报与长图导出系统（CardPoster）
- 典雅画报风与文艺拍立得风双模实时光栅化渲染，内置二维码与精选背景，支持保存至系统相册或系统原生分享。

### 9. 卡片 AI 伴学深度追问与流式对话面板（CardFollowUpChat）
- 4 组启发式引导词（💡/🔍/⚡/❓），流式打字光标效果、朗读回答与一键复制。
