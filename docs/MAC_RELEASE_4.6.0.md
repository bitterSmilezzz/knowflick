# KnowFlick macOS v4.6.0

发布日期：2026-09-28。最低 macOS 14。

## 本版变化

- **学习地图上线**（roadmap P2 主线 UI 的 mac 侧补齐，与 Android 同一产品口径）：侧栏「学习」分组新增「学习地图」，按 **学科 → 分支 → 难度** 三级回答「我现在学什么」：
  - 第一层学科行显示卡数 / 已看 / 已掌握 / 支线数与发丝边进度条，点击钻入分支层；
  - 分支卡提供两个动作——**专学这条支线**（应用后直接进刷卡，按 `orderKey` 一级一级往前推）与**加入混合**（多条支线并进同一卡堆混着刷，可再点移出）；
  - 分支层底部是**按难度选**的阶梯芯片（如「L2 基础 3/8」），只选难度时自动按顺序推进；「未分级」片同样支持钻取。
- 范围生效时**接管卡堆的分类维度**（偏好分类让位）：刷卡页顶栏显示范围徽标（范围描述 + 剩余张数），点击一键退出回到全景；副标题同步显示当前范围。侧栏「学习地图」行的计数徽标显示范围内剩余张数。
- 顺序推进跳过背景图防重打散（「一点点看」的导入顺序就是产品语义）；撤销划卡回到该卡在 `orderKey` 上的原位。范围只在本次会话内生效，重启自动回到全景。
- `StudyScope` / `StudyMap` 纯逻辑模块入 Core，与 Android `domain/StudyScope.kt` 逐条对齐（含同名分支 slug 跨学科隔离、未分级独立成片、掌握≠看过等契约）；`DeckDeriver` 新增学习范围入参，历史行为在范围缺省时逐字节不变。

## 安装与升级

下载 `KnowFlick-4.6.0.app.zip`，解压后放入 Applications。已有卡库继续使用，无需重置。
附件 `KnowFlick-4.6.0.app.zip.sha256` 用于核对下载完整性。

## 验证与边界

- 本机 `./tools/test.sh --core-only` 352 项测试全绿（新增 `StudyScopeTests` 11 项，含 2 项 DeckDeriver 接入用例）。
- SwiftUI 层（`LearningMapView` / 侧栏目的地 / 刷卡页徽标）本机无法编译，以 CI（完整 Xcode）构建与测试为准。
- 星图 / 测验 / 听书面板的 Cutline 原生化仍留待下一批（延续 v4.5.0 边界）。
