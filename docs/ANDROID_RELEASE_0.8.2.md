# Android 0.8.2 模拟环境修复记录

日期：2026-09-14。按“先解决模拟环境中的软件问题，最后再处理实际环境”的顺序，本轮只对 Android 15 ARM64 模拟器中的应用逻辑、界面、存储、网络和发布包进行修复与验证，未连接用户手机。

## 修复内容

### 状态与交互

- 保存测验翻面状态，Activity 重建后继续显示当前答案。
- 连接测试状态不再跨重建恢复，避免取消中的请求永久显示“测试中”。
- 详情页 HTTP/HTTPS 参考链接可以交给系统浏览器打开。
- 设置页适配软键盘、320dp 窄屏和横屏；密钥输入按密码字段显示。
- 测验跨轮记录已出现卡片，完整卡池耗尽前不再重复。

### 数据与文件

- JSON 归档按 ID、再按规范化标题合并。已有卡保留本机 ID 并恢复正文、来源、收藏、浏览和学习进度；新增卡保留有效归档 ID；空标题会被拒绝。
- 导入改为后台受限流式读取，单个归档上限为 25 MiB，取消页面任务时同步取消读取。
- 卡片、设置和语音设置使用同目录临时文件、`fsync` 与原子替换写入；卡片快照经串行后台队列按顺序保存，`onPause` 不再等待磁盘写入。
- JSON、Markdown 与 Anki 导出通过 `FileProvider` 分享真实文件，并只授予接收应用临时读取权限。

### AI 与语音

- 本地 AI 和本地语音请求不再携带旧的云端 Authorization；切换到本地服务时删除已保存的对应云端密钥。
- 修正 DeepSeek 空配置的默认 Base URL 和模型、自定义服务的必填密钥规则，以及基于 URI 主机名的服务商和回环地址识别。
- OkHttp 请求支持协程取消；停止语音会取消远程请求并阻止迟到响应启动播放。
- 系统 TTS 改为首次朗读时初始化；User-Agent 使用实际安装版本。

## 当前边界

模拟服务由设备内 MockWebServer 提供，覆盖成功、错误和取消路径，没有调用真实付费 AI 或语音服务。模拟器不能覆盖厂商系统限制、实体设备性能、真实网络、系统 TTS 差异和用户手机上的既有异常；这些按约定留到下一阶段处理。
