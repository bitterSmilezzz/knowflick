## M1 里程碑：存储底座与工作台骨架（当前阶段）

### 1. 核心目标
将应用从「单 JSON 刷卡玩具」改造为「高性能离线生产力工作台」，把持久化与搜索地基打牢，无任何 AI 配置也能作为极致丝滑的本地知识库。

### 2. 改造内容
- **Rust 后端**：
  - 引入 `rusqlite` 与 `bundled` 特性，建立 `knowflick.db` 并应用 `DATA_MODEL_SECOND_BRAIN.md` 的 DDL；
  - 接入 `tauri-plugin-global-shortcut` 与 `tauri-plugin-tray-icon`，实现托盘与快捷键（默认 `Alt+Space` / `Option+Space`）唤出悬浮窗口；
  - 实现从旧 `cards.json` 的无损热迁移；
  - 实现基于 FTS5 的高性能全文检索 command。
- **前端工作台**：
  - 重写界面骨架为三栏结构（侧边栏导航 + 中间知识流列表 + 右侧详情阅读）；
  - 实现极简悬浮闪念胶囊窗口（Quick Capture）；
  - 全局加入 `ErrorBoundary` 与崩溃防护横幅；
  - 列表加入轻量虚拟滚动支持，确保千条数据流畅滑动。

### 3. 验收标准与验证命令
- `./tools/verify_workbench.sh` 编译并跑通所有测试；
- 启动应用，按 `Option+Space` 能够瞬间在屏幕中央呼出悬浮胶囊；输入一行文字回车，即刻进入 Inbox；
- 在主窗口按 `⌘K` 进行中文搜索，能够高亮匹配标题与全文。

## M2 里程碑：多源收集与 AI 提炼

### 1. 核心目标
解决「信息碎片进不来」的核心痛点，打通网络链接与本地文档的无痛输入管道，并让大模型承担最耗时的结构化加工。

### 2. 改造内容
- **多平台链接智能嗅探（Sniffer Pipeline）**：
  - GitHub 适配器：调用公开 API 读取 Repo 简介、README 关键段落与 Star 数；
  - B站视频适配器：解析视频标题、简介、分P、弹幕热词；
  - 微信/文章通用适配器：升级 HTML 正文提取规则，遇反爬时自动提示读取剪贴板正文兜底；
- **本地文档解析引擎**：
  - 纯本地提取 Markdown、TXT、DOCX、PDF 的纯文本与标题层级；
- **AI 服务层重写**：
  - 界面提供主流厂商一键预设（DeepSeek、智谱、Kimi、通义千问、OpenAI、Claude、Ollama）；
  - 支持 SSE 流式传输与 Token 用量统计；
  - 智能切片 Prompt：将长文章/文档自动切分为多个原子知识卡并推荐标签。

### 3. 验收标准
- 复制 GitHub 仓库链接，呼出胶囊粘贴，自动解析出标题、README 摘要并保存入库；
- 拖入一个 `.docx` 文件，AI 自动切片为 3–5 张带标签的原子知识卡并进入确认流。

## M3 里程碑：第二大脑问答与简报

### 1. 核心目标
将碎片化的海量知识沉淀为可对话、可查询、能主动提供洞察的个人第二大脑。

### 2. 改造内容
- **语义向量检索**：
  - 本地轻量 Embedding 推理（Qwen3-Embedding-0.6B 或 bge-small-zh）；
  - 集成 `sqlite-vec`，在 SQLite 内部实现向量相似度计算；
  - 实现 BM25 + 向量余弦相似度的 RRF（倒数排名融合）算法；
- **知识库问答侧栏**：
  - 在主界面右侧提供 AI 对话抽屉；
  - 用户提问时自动召回 Top-K 相关卡片与素材作为上下文，回答严格附带卡片引用溯源；
- **周期性认知简报（Cognitive Briefing）**：
  - 固定的三板块生成：① 本周收录聚类 ② 关注趋势演变 ③ 待温故的旧内容；
  - 支持一键将简报保存至认知产物表（Layer 3: Artifacts）。

### 3. 验收标准
- 针对知识库中存过的某篇专业技术文章进行模糊概念提问，AI 能够精准命中原文并给出总结，附带卡片跳转链接；
- 能够点击「生成本周洞察」，生成固定三模块的 Markdown 简报。

## M4 里程碑：温故复习与打包分发

### 1. 核心目标
将既有算法资产无缝复用，补齐开放导出与数据主权闭环，完成多平台安装包自动化打包，达到对外正式分发标准。

### 2. 改造内容
- **温故知新官方插件**：
  - 将原 Tinder 划卡、SM-2/FSRS 测验视图、掌握度统计整体封装为内置插件；
  - 设置中提供一键启用/禁用开关；
- **开放导出体系**：
  - 一键导出为带 YAML Frontmatter 的 Markdown 文件夹（支持 Obsidian 直接读取）；
  - 一键导出完整系统级备份包（`.kfbackup`）；
  - 自动化往返导入导出无损一致性测试；
- **跨平台安装包发布与名称最终确定**：
  - 根据确定的品牌名称更新 App 图标、Bundle ID、安装包元数据；
  - 跑通 Windows（`.msi`）、macOS（`.dmg`）与 Linux（`.deb`）本地与 CI 自动化发布工作流。

### 3. 验收标准
- 导出的 Markdown 文件夹在任意第三方笔记软件中正常解析层级与标签；
- `workbench-release.yml` 成功构建出对应平台的安装包且安装冒烟测试全部通过。
