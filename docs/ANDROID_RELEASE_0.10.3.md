# KnowFlick Android v0.10.3

发布日期：2026-10-02。versionCode：23。最低 Android 8.0 / API 26。

## 本版变化

- 收藏与历史页采用提供选中语义的 Tab 和 Material FilterChip，触控高度至少 48dp；标签改为简洁的功能名称。
- 浅色主题主色加深，提高白字对比度；显式设置 Material 前景和容器颜色，保持纸张主题一致。
- 学习计划与统计缓存纳入日期、时区，监听日期、时钟、时区变化与恢复前台，避免午夜后沿用旧统计。
- 热力图连续天数使用完整活动日期，超过 35 天不再截断；今天尚未活动时保留昨天的连续记录，补充读屏日期文本。
- 计划排程缓存、掌握度取整与边界处理改进；全局媒体入口改为弱引用持有语音控制器，使用中的控制器仍由 ViewModel 持有。
- 汇总前序去 AI 味调整及关闭同步面板时取消同步的修复。

## 安装与升级

下载 `KnowFlick-0.10.3.apk`。使用既有发布证书签名，可覆盖安装并保留数据；更新前可导出备份。
附件 `KnowFlick-0.10.3.apk.sha256` 用于核对下载完整性。

## 验证与边界

- 269 项 JVM 测试、43 个套件通过；Debug Lint 与 Release/R8 构建、签名及 ZIP 对齐校验通过。
- Lint 无错误，仍有 40 个既存警告和 2 项提示。
- 本机没有连接 Android 设备，未执行设备交互、日期广播和后台语音播控验收。
- 双端排程算法与同步重试的阻塞等待仍需专项处理。详见 [深入优化记录](DEEP_REFINEMENT.md)。
