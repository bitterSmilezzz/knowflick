## 一、核心升级维度

### 1. 交互式全景知识星图 (Interactive Knowledge Graph)
- **`KnowledgeGraphEngine` 领域引擎**：
  - 基于结巴分词轻量切词与倒排索引，建立关键词交集与 Jaccard 相似度量；
  - 结合跨学科引力与学科内强聚类算法，将数百张离线卡片聚类生成星宿拓扑网络；
  - 自动提取星宿核心主题与互联引力连线（11,700+ 关联引力通道）。
- **`KnowledgeGraphScreen` 全景画布**：
  - 基于 Compose Canvas 实现高性能渲染，支持双指平滑手势缩放、自由平移漫游；
  - 动态连线引力场：区分学科内与跨学科引力光索；
  - 节点点击呈现双层同心光环高亮，底部弹出即时知识微卡片预览，支持一键置顶进入卡堆或跳转详情；
  - 顶部嵌入横向滑动分类 Chip（全景星系、AI、AI Agent、AI 开发、中级会计、冷知识）与全文检索栏。

### 2. 拟真物理音效与触感 (Procedural Soundscapes & Audio FX)
- **`AudioEffectHelper` 纯代码实时波形合成**：
  - 纯 Kotlin / AudioTrack 实现 16-bit PCM 波形内存合成，0 外部音频文件引入（**0 KB APK 资源开销**）；
  - 粉红噪声纸张滑动沙沙声（`playPaperSlide`）：模拟真实纸张翻动时的摩擦白/粉噪声；
  - 卡片利落翻折脆响（`playCardFlip`）：模拟卡牌瞬间翻转的清脆敲击声；
  - 双音和谐五度泛音掌握音（`playMasteryChime`）：模拟清澈水滴泛音；
  - 微机械点击反馈（`playClick`）：模拟复古微动按键触感声。
  - 完美遵循系统免打扰与静音模式，在「AI 服务设置」提供可视化开关。

### 3. 纸质人文视觉主题系统 (Paper Theme System)
- **4 款精调纸质底色色板**：
  - **宣纸白**（`#FAF9F6` 温暖米白）：温润柔和，如抚手造质感纸张；
  - **复古羊皮纸**（`#F5EEDC` 古籍驼黄）：沉淀典雅书卷底色；
  - **晨雾冷灰**（`#F0F2F5` 清朗灰调）：宁静专注的现代排版灰；
  - **暖曜黑**（`#121215` 人文暗色）：柔和深邃护眼暗色；
  - **跟随系统**：自动感应深浅色模式自适应切换。
- **全平微结构与发丝边框**：
  - 全面贯彻 1px 微发丝边框与低饱和平托盘，在「AI 服务设置」提供可视化色板卡片实时切换与持久化。

### 4. 局域网端对端无感同步 (LAN P2P Zero-Cloud Sync)
- **内置纯 Java 标准库 HTTP 传输服务（`SyncServer` / `SyncClient`）**：
  - 基于纯 `ServerSocket` 实现轻量高效内置 HTTP 传输服务，支持 6 位动态配对码安全鉴权与自动发现；
  - 零中转、零云端依赖，局域网/热点端对端双向无感增量合并；
  - 智能比对最新版本、合并收藏阁与历史足迹，并自动进行 SM-2 / FSRS 记忆排程状态对齐；
  - 顶部与菜单集成「局域网极速同步…」优雅半屏抽屉面板（`SyncSheet`），支持一键复制本机 IP 与一键双向极速合并。
