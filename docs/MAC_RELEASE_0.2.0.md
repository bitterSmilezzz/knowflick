# KnowFlick macOS v0.2.0

发布日期：2026-10-02。最低 macOS 14。

## 本版变化

- 学习工作台以阅读内容、今日进度和到期复习为主，调整摄影卡片、分类目录、字阶和间距；简化重复说明与装饰性效果。
- 侧栏折叠后 logo 与展开按钮共用位置；图标悬停显示标题和操作说明，移出或点击后隐藏。窄窗口自动收起导航文字。
- 统计图随可用宽度排版，趋势按峰值缩放并补充日期标签；复习说明与实际 1、3、7 天规则保持一致，掌握度标明为估算。
- 搜索条件变化即作废旧任务，卡库修改后刷新结果，关闭后停止提交；检索中阻止打开旧结果，不提前显示空结果。
- 学习计划在跨日、时区或时钟变化、唤醒及恢复前台后刷新；复习日期与统计改为一次聚合并缓存。
- 卡片与设置保存告警分别保留，设置写入失败不再被卡片保存成功清除。
- 汇总前序去 AI 味调整：减少 sparkles、彩色光晕和 emoji 提示，保留内容摄影与表达来源的 AI 标记。

## 安装与升级

下载 `KnowFlick-0.2.0.app.zip`，解压后替换原应用。已有卡库继续使用，无需重置。
附件 `KnowFlick-0.2.0.app.zip.sha256` 用于核对下载完整性。

## 验证与边界

- 361 项 Swift 测试、46 个套件通过；发布构建、签名校验、资源与启动自检通过。
- 本机已检查首页、复习、知识库、统计、窄窗口及搜索主要状态；自定义侧栏悬停浮层完成编译验证，尚未用自动化重现指针停驻画面。
- 未做性能基准测量，不声明具体耗时降幅。排程算法与 Android 的差异仍保留，本版不迁移旧数据。
