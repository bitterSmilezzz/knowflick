# KnowFlick macOS v4.3.0

发布日期：2026-09-22。最低 macOS 14。

## 本版变化

- 新增统一学科、分支、难度数据契约，旧卡片可从分类派生学科坐标，保留原有学习记录。
- 知识星图分片与缓存优化，减少不影响拓扑的操作引发的重复计算。
- 新增听书控制台：语速、音调、进度定位、睡眠定时、四档场景预设与结束前淡出；快捷键 `⌥⌘P` 打开。
- 汇总纸质主题、局域网同步、搜索历史、AI 追问沉淀、测验错题复盘及学习统计改进。
- 新增本地 MCP/CLI 与 Qoder 配套 Skill，提供知识检索、学科地图和学习路径。写入仅进入待确认队列，长连接自动刷新，并发暂存受锁保护。
- 网页剪藏内核与抓取服务已具备，但 macOS 剪藏界面入口尚未接入，本版不提供该入口。

## 安装与升级

下载 `KnowFlick-4.3.0.app.zip`，解压后放入 Applications。已有卡库继续使用，无需重置。
附件 `.sha256` 用于核对下载完整性。MCP/CLI 使用说明见仓库 `tools/knowflick-mcp/README.md`。

## 验证与边界

本机运行 Core 测试；完整 SwiftUI 构建、打包、签名校验与启动检查由 GitHub macOS workflow 执行。
本版尚未提供系统媒体键/控制中心集成与关窗继续播放开关；Windows 客户端仍未实现。
