# macOS 优化验证（2026-09-09）

本轮仅处理 macOS 原生应用。

- 修复远程语音生成期间无法暂停，以及下一段音频忽略暂停的问题；停止会取消等待。
- 试听失败回退到系统语音时保留试听选择的语速和音色；取消按正文中出现“粤语”一词就切换方言的规则。
- 语音设置增加生成状态、停止播放和错误提示，正确区分标准与增强音色。
- 接通进入详情页自动朗读开关；已有同卡播放或连续朗读时不重启。
- 统计分类名称允许换行；详情照片上的按钮固定白色文字，修复浅色模式对比度。
- 保留当前图标，构建前用 ImageIO 解码所有尺寸并逐像素比较 1024px ICNS 与 PNG。移除没有对应 asset catalog 的 CFBundleIconName，仅使用 CFBundleIconFile。

验证：完整 Swift Testing 测试 84 项通过（含新增 5 项语音测试）；暂停回归测试在修复前失败、修复后通过。Release 构建与签名验证通过。原生界面已检查主卡片、折叠菜单、语音设置、试听和停止操作。

语音配置支持保存多套云端或本地服务配置，每次选用一套。系统语音无需密钥或模型文件；本地模式连接兼容 /audio/speech 的运行中服务，由服务加载模型文件，应用不直接导入权重。云端音质和本地模型端到端合成仍需可用服务实测，本轮没有调用这些服务，系统试听验证仅证明播放控制工作正常。

## 后续优化

- 将设置、测验、星图、收藏和当前卡片朗读快捷键注册到 macOS 原生菜单栏，不再依赖展开窗口内的菜单。存在弹窗时禁用主窗口命令，避免覆盖当前面板。
- 帮助页统一使用 ⌘K 开启测验，保留 ⌘Q 的系统退出行为，补充 ⌘, 设置说明。
- 清空语音密钥或移除配置时同步删除对应钥匙串条目；删除失败向设置页报错。新增可注入的凭据存储接口，测试不访问真实钥匙串。
- 完整测试增加至 86 项，全部通过；新增用例覆盖清空、移除、重启恢复和删除失败。
- 最终 Release 构建及签名验证通过。原生操作确认首次按 ⌘, 可打开设置，关闭设置后 ⌘K 可打开测验，在设置页内 ⌘K 不会覆盖面板。760px 窄窗口下当前卡片标题完整换行，菜单和底部按钮可见，检查后已恢复窗口尺寸。
- 语音请求会清理复制粘贴带来的空白，拒绝空模型或空音色；网页、JSON、XML 和空响应不会再被误当成音频。无可用卡片时不会进入连续朗读状态。
- 全文搜索结果的长标题现在完整换行；搜索结果列表保持摘要两行预览。
