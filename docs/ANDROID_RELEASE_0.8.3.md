# Android 0.8.3 卡片滑动修复记录

日期：2026-09-14。用户在手机上报告“手指滑动切换效果不好，切换之后又会显示上一个内容，不丝滑”。本轮继续按既定顺序先在 Android 模拟环境中复现、修复并验证。

## 根因与修复

原实现每次收到手指位移后，让一个弹簧动画追赶目标位置。连续手势会不断取消并重启弹簧，因此画面明显落后于手指。松手切换后，新顶卡又会在旧卡飞出期间被设为全透明；同时未按卡片 ID 固定组合身份，飞出层重新创建时还要等待异步背景图状态。这些行为叠加后形成卡片切换迟钝、旧内容回显或闪灰的观感。

修复后：

- 拖动阶段直接使用当前手指位移更新图层，下一帧即可跟随；只有不足切换阈值时才执行弹簧回弹。
- 底层卡根据拖动进度同步抬升；达到阈值后，新顶卡立即显示在旧卡下方。
- 旧卡从释放位置继续移动，以 220ms 补间动画淡出，不再使用持续时间不稳定的离场弹簧。
- 每张卡用卡片 ID 固定 Compose 组合身份，避免列表换位时复用上一张卡的状态。
- 飞出层先从 12 MiB 内存缓存取得背景图，避免异步加载开始前闪灰一帧。
- 新卡在旧卡离场期间不接收点击或拖动，防止动画重叠。
