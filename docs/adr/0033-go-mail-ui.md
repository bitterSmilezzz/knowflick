# 第二阶段第二十四刀：邮箱能力挂到 Go 应用与预览界面

> 承接 ADR-0032。定时器有了但没人启动；这一批把它挂到应用上，并给出界面入口。

## 一、迁了什么

| 能力 | Go | 说明 |
| --- | --- | --- |
| 邮箱服务 | MailService | 列账号、手动跑一轮、自动同步启停与状态 |
| 只读保护 | requireWritable | 只读打开资料库时明确拒绝：同步会写库，请先启用编辑 |
| 连接复用 | connection | 同步串行，一个库连接足够；换库时关旧开新 |
| 界面入口 | 预览页「邮箱」折叠面板 | 账号列表、立即同步、自动同步间隔与启停 |

## 二、界面保持首层简洁

邮箱面板默认收起，只在可写资料库下出现，放在笔记列表上方。
这符合项目约定：首层简洁，功能通过多级入口展开。

界面上显示每个账号是否有凭据、上次错误，以及自动同步是否运行、跑了几轮。
密码本身**不出现在任何 DTO、界面或日志里**——沿用前几批的口径。

## 三、一个自更新的嵌入守卫

TestEmbeddedBundleIsCurrent 早期把 bundle 哈希写死成常量，UI 一改就得手动改测试。
改成从磁盘上的实际产物读取 index-*.js，再断言嵌入的 index.html 引用的是同一个。

这样既跟随 UI 变化，又仍能抓住「只跑了 Vite 没重新 go build」导致的旧前端。

## 四、验证

| 用例 | 内容 |
| --- | --- |
| Go 4 项（MailService） | 只读资料库被拒；未打开资料库被拒；自动同步启停（重复启动不产生第二个循环、停止幂等）；间隔 0 被拒；启动后立即跑第一轮（不等 60 分钟） |
