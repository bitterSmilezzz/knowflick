# ADR-0004：以笔记、知识库与应用作为产品主线

- 日期：2026-10-24。
- 状态：**产品范围按本次用户指令更新；界面、实体增补与交付顺序为提案，尚未实现**。
- 范围：补充 ADR-0003，保留 ADR-0002 的桌面/Web 与 Android 分工。
- 方案入口：[产品重规划](../product/README.md)。

用户要求保留现有能力，并将来源扩展到完整笔记、多模态、邮箱、第三方笔记和移动平板，再组织为知识库、用于学习、复盘、画像、项目记忆和创作。因此不再沿用旧产品规划中“不做长文笔记编辑”的范围限制：**笔记成为持续编辑的一等资产；知识卡保留为学习和知识提炼的一种形式**。

知识库以范围、引用和用户确认的知识组织笔记，应用读取所选范围生成可追溯产物。拒绝把所有原文先压成卡片再参与使用的路径，因为它丢失长文语境、阻碍写作并制造重复。代价是新增笔记修订、稳定引用及旧模型迁移责任，不能只重命名素材页面。

本地基础无需模型与账号，标准产品不含我方托管云订阅；用户自选存储、按需模块和开放出口进入路线。默认三入口、结构化笔记正文、可重建索引、同步协议及画像治理等细节见产品目录，作为后续小批次实现与验证的依据。它们不构成已经上线、已经通过性能验收或已获用户逐项选型确认的事实。
