# KnowFlick macOS v4.4.0

发布日期：2026-09-23。最低 macOS 14。

## 本版变化

- 听书播放状态、卡片标题与分类显示在系统控制中心；停止朗读时清除状态。
- 媒体键与触控栏支持播放、暂停、下一张、上一张及前后跳转 10 秒。切换卡片沿用应用的划卡与撤销记录。
- 修复朗读引擎与播放状态短暂不一致时，暂停或恢复可能无法更新应用状态的问题。

## 安装与升级

下载 `KnowFlick-4.4.0.app.zip`，解压后放入 Applications。已有卡库继续使用，无需重置。
附件 `KnowFlick-4.4.0.app.zip.sha256` 用于核对下载完整性。

## 验证与边界

本机使用 CommandLineTools 运行 Core 测试与 Core 构建；完整 SwiftUI 测试、应用打包、签名校验、资源和启动检查由 GitHub macOS workflow 执行。发布前需确认 main 与 tag 对应的 workflow 均成功。
Core 单测验证状态映射和指令回调；系统控制中心与媒体键的真实会话行为仍需在解锁的 macOS 图形会话中验证。关窗后重新打开窗口的行为未由本版验证或修复。
