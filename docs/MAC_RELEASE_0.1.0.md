# KnowFlick macOS v0.1.0

发布日期：2026-09-29。最低 macOS 14。

> **版本序列切换**：自本版起 mac 改用 pre-1.0 序列，如实反映「mac 尚非正规产品」的定位。
> `v4.6.0` 为旧 4.x 序列末版，其间的历史 tag/Release 全部保留（说明见 [多端协作规范](MULTI_PLATFORM.md)）。

## 本版变化

- **界面 Cutline 迁移收官**：
  - 收藏 / 统计单一路由化——旧面板功能平移进侧栏 Cutline 页（分类筛选、全文搜索、笔记导出、艾宾浩斯概览、未来 7 天到期预测、分类分布下钻历史），收藏阁 / 学习统计 / 历史记录的菜单与 menubar 入口一律导航侧栏目的地；`FavoritesView` / `StatsView` 归档。
  - 测验与听书控制台原生化——档位 / 语速 / 音调 / 翻卡停顿 / 睡眠定时五组单选胶囊重构为分段形态，测验卡片改浮卡描边；测验流程、档位反推（语速 + 音调 + 翻卡停顿反推）、滑块与快捷键逻辑原样。
  - 全仓色彩语言统一——琥珀主色语义归位选中蓝（13 个视图），琥珀仅保留 AI 徽章与入口、错误警告、「犹豫想起」评级；刷卡页顶栏与内容区脚手架按钮组垂直居中。
  - 导入笔记 sheet 修复选择器溢出卡片边界的问题，主按钮按解析引擎条件配色（AI 档琥珀 / 规则档蓝）。
- **刷卡卡片恢复整张分类摄影底图**（多阶暗化 scrim + 白字排版，Cutline 结构不变），收藏卡片补缩略图；侧栏品牌标改用真实 App 图标（与 Dock 一致），折叠态撞图标去重。
- **性能**：消除侧栏每帧重建 LearningPlan（×2）、工作台每次求值重建、统计页一次渲染重建 5+ 次的三处热点（改为按卡库变化缓存 / 单次计算下发）；历史页时间格式化器改静态单例。实测冷启动到窗口出现 2.1 秒、浏览多页后内存约 17 MB。

## 安装与升级

下载 `KnowFlick-0.1.0.app.zip`，解压后放入 Applications（或替换仓库 `dist/KnowFlick.app`）。已有卡库继续使用，无需重置。
附件 `KnowFlick-0.1.0.app.zip.sha256` 用于核对下载完整性。

## 验证与边界

- 17 个界面（含全部 sheet）× 浅色 / 深色双主题完成实机走查：下载 CI 构建（full Xcode 编译产物）本机运行，截图逐页核对布局、对齐与配色语义。
- KnowFlickCore 整模块 Swift 6 严格并发 typecheck 通过；CI 全量 Swift 测试、打包、资源完整性与启动自检全绿。
- 本机 Command Line Tools 无法展开 SwiftUI 宏（`docs/MAC_TOOLCHAIN_2026-09-27.md`），UI 层编译验证以 CI 为准。
- 星图保留深空视觉分区（未做 Cutline 化，为有意设计）；学习地图、Agent 本地 MCP 等能力已在此前版本交付，本版不含其变更。
