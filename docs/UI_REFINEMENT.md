# macOS 学习工作台 UI 调整

2026-10-01。范围：今日、复习、知识库、侧栏与公共控件。保留导航目的地、内容、摄影资源、快捷键和数据流程。

## 设计判断

原界面在同一页叠加宣传式标题、带编号的学习路径、大块统计容器和同款主题卡片，实际阅读内容被挤到第二层。此次改为内容优先的原生学习工作台：阅读是主区，到期复习是独立任务区，统计是摘要，主题是目录。

| 问题 | 调整 |
| --- | --- |
| 首页与知识库使用口号式标题 | 改为实际页面名称，日期与学习状态承担上下文 |
| 每个主题重复卡片、图标强调与进度条 | 改为紧凑目录行，直接显示总数与掌握张数 |
| 学习路径固定显示 01/02/03 | 根据真实到期数量显示复习任务，保留阅读与导入入口 |
| 图片上叠加标签和遮罩 | 把分类移到图片外，保留照片本身作为阅读入口的视觉锚点 |
| 低对比文字与过度统一的圆角 | 提升次要文字对比，缩小容器圆角；首页统计依靠留白分区 |
| 导航、筛选、悬停都有弹簧或缩放 | 导航与筛选即时反馈，悬停仅改变表面；按压幅度减小 |
| 0% 进度仍有彩色圆点 | 填充宽度允许为零，补充读屏进度值 |
| 默认窗口尺寸也被用作最小尺寸 | 最小尺寸改为 900×640；不足 1040pt 时自动显示图标侧栏，不改写用户的展开偏好 |
| 图标按钮缺少读屏名称 | 补充搜索、收藏、编辑与导航名称、计数、选中状态 |

## 参考与取舍

使用 `redesign-existing-projects` 和 `frontend-ui-engineering` 的现有项目审视方法，按原生 SwiftUI 语境应用。落地页技能的营销结构不用于学习工作台。

本机 ui-research 的参考入口：

- [08：信息分区](../../../ui-research/ui/08-farhan-video-dashboard-info-partition.md)：内容、任务与汇总承担不同视觉权重；彩色只保留给交互与状态。该案例是静态图，本轮只采用其信息分区方法。
- [18：界面检查表](../../../ui-research/ui/18-web-interface-guidelines-frozen-checklist.md)：高频操作不依赖装饰动画，按压幅度保持轻微。
- [21：频次与动效](../../../ui-research/ui/21-ui-animation-frequency-inversion-and-curve-fitting.md)：任务响应不等待动画，系统减弱动态效果对应 SwiftUI 的 accessibilityReduceMotion。

明确不增加的动效：

1. 页面切换整屏滑入：每日反复导航，位移没有增加信息。
2. 主题目录交错入场：目录用于定位内容，入场等待增加搜索成本。
3. 按钮悬停放大：重复出现并改变几何，保留表面反馈即可。
4. 装饰性呼吸、发光与渐变：没有对应业务状态。

数字与实际进度变化保留轻量反馈，并尊重系统减弱动态效果。侧栏开合仅在几何变化时过渡，键盘和导航动作即时生效。

## 2026-10-02：侧栏悬停与折叠入口

- 导航、搜索、导入、剪藏、设置与帮助均使用原生悬停提示，解释入口用途；有计数的导航显示对应实时数量，选中项标注当前页面。
- 折叠后 Logo 与展开按钮共用一个 40pt 控件：平时显示 Logo，悬停时显示侧栏图标；点击原 Logo 位置展开，取消原来独立的展开按钮行。
- 窄窗口仍提示需要加宽，不改写自动折叠规则；品牌悬停不使用缩放或装饰动画。
- 发布构建与启动自检通过；原生检查确认两种侧栏形态的帮助文本、折叠布局及 Logo 点击展开行为。

### 折叠态自定义提示补齐

此前只配置了系统 help 文本，没有实现侧栏旁的悬停浮层。本次新增统一提示层：折叠后的导航、搜索、Logo 与底部工具停留 200ms 后显示名称、用途与相关计数。提示在整壳上绘制，避免被侧栏 ScrollView 裁切；不接受鼠标事件，不影响点击导航，离开或点击立即收起。展开态继续采用系统 help。发布构建与启动自检通过。
