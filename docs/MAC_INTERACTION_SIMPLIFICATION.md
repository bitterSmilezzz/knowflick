# macOS 交互简化

2026-10-03。本轮只改 macOS，承接 0.2.0 的视觉优化，减少使用时需要判断的入口。

## 调整

| 场景 | 原来 | 现在 |
| --- | --- | --- |
| 主导航 | 11 个目的地加独立导入、剪藏入口 | 今日、复习、知识库、统计 4 个常驻目的地；刷卡、地图、测验、星图、听书统一放在更多工具 |
| 收藏与历史 | 独立页面，操作方式不同 | 知识库中的全部、收藏、历史范围；菜单与快捷键仍能直接进入对应范围 |
| 今日学习 | 进度、3 个统计、复习安排、主题目录与多条路径 | 进度、下一篇阅读、到期复习；浏览未读作为次级入口，添加资料移至知识库 |
| 知识库 | 5 个筛选按钮、主题选择器、排序、导出与两个添加按钮 | 范围切换、搜索、筛选菜单；添加和整理分别承载输入与输出 |
| 刷卡顶栏 | 搜索、听书、外观切换与 15 项功能菜单 | 听书及 3 项刷卡选项；全局搜索和设置保留在固定入口 |
| 工具退出 | 固定跳到刷卡或复习 | 星图、测验、听书返回进入前的主页面 |

收藏和历史沿用实际卡库与历史集合，不迁移数据。历史按浏览时间排序；筛选条件可见并可一键清除。导出、编辑、追问、分享海报保留在知识库或卡片菜单。

## 参考与取舍

参考本机 ui-research/ui/README.md 的常驻界面克制和同一控件多状态原则。本轮的导航分组是针对 KnowFlick 的设计判断，不宣称为案例库统一规范。未增加动效、装饰性渐变或新的功能包装名称。
